# Проверенные инциденты

Сюда через обычный PR можно перенести только очищенные и завершённые incident records. Сырые логи, токены, переписка и временный runtime store в SSOT не добавляются.

Исходное сообщение владельца остаётся неизменяемым фактом после sanitization; гипотезы ИИ хранятся отдельно и становятся принятым уроком только после evidence и независимого review.
