# Roadmap Guardian — read-only

Проведи read-only аудит текущего Roadmap. Не оценивай прогресс по числу закрытых Issues. Проверь: capability/outcome coverage, oversized/undersized Issues, Verification Gap, false progress, dependencies/cycles/starvation, stale READY, architectural drift, technical debt budget/interest, value drift и необходимость QCP/ACP. Выдай findings с evidence и конкретными safe remediations. Не меняй product strategy без `human:required`.
