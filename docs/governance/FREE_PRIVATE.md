# Профиль FREE_PRIVATE

Нулевой денежный бюджет. Default executor — self-hosted. Hosted GitHub/GitLab quota выключена до свежего quota evidence и spending limit `0`. Mandatory checks не требуют AI/API.

GitHub Free `2 000` Actions-минут относятся к private repositories. Standard GitHub-hosted runners для public repositories бесплатны и зарегистрированы отдельной capability; larger runners платные. Профиль не переключает repository в public и не включает ни один hosted provider автоматически.

Для private hosted quota внутренний нормальный предел — 1 400 минут, hard stop framework — 1 600, резерв — 400. Artifact upload блокируется выше 350 MB, cache — выше 2 GB. Это внутренние ограничения безопасности; перед включением всё равно нужны свежие официальные plan facts, usage и подтверждённый provider budget `$0` с stop usage.

Active autonomy — A1 до certification; promotable maximum — A2, risk ceiling R1. Auto-merge отключён. Direct `main` development и production deploy запрещены процессом. Ограничения бесплатного GitHub plan не имитируются: protected branches/rulesets доступны GitHub Free только для public repositories, поэтому в private FREE_PRIVATE trusted controller требует independent exact-SHA approval, а Control Center оставляет Security/общий режим ограниченными из-за риска ручного обходного merge.
