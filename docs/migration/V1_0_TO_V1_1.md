# Migration v1.0 → v1.1

1. Создать backup/tag текущего governance baseline.
2. Выполнить `python .adwf/migrate_v1_0_to_v1_1.py` (dry-run).
3. Просмотреть план.
4. Выполнить с `--apply` в отдельной governance branch.
5. Синхронизировать новые labels и Project fields.
6. Заменить/добавить ADWF workflows.
7. Настроить project-specific commands и Golden Paths: до этого product gates остаются `NOT_VERIFIED/N/A`, а не PASS.
8. Выполнить `python .adwf/adwf.py doctor`.
9. Выполнить `python .adwf/adwf.py self-test`.
10. Провести Baseline Certification/Reality Check.
11. Только после PASS включать A2/A3 progression.

Migration не должна автоматически повышать autonomy или ослаблять существующие gates.
