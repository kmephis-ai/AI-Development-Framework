# Миграция ADWF v1.3 → v1.4

v1.4 меняет обязательный default на `FREE_PUBLIC_GITHUB`. Миграция **никогда не делает repository public молча** и не выбирает LICENSE за владельца.

## Безопасный preview

<!-- adwf-doc: skip(reason=migration-engineer-fallback) -->
```bash
python .adwf/migrate_v1_3_to_v1_4.py --root .
```

Без явного подтверждения public/license apply должен завершиться `HUMAN_REQUIRED`.

## Применение после решения владельца

<!-- adwf-doc: skip(reason=migration-engineer-fallback) -->
```bash
python .adwf/migrate_v1_3_to_v1_4.py --root . --apply --public-confirmed --license-acknowledged
```

Миграция создаёт backup и journal `.adwf/migrations/v1.3-to-v1.4-journal.json`, сначала записывает `PREPARED`, затем config/state/effective policy, выполняет readback и только после этого фиксирует `COMMITTED`. Ошибка между записями вызывает восстановление backup и `ROLLED_BACK`.

После миграции autonomy не считается повышенной, а Control Plane/Product Health остаются `NOT_VERIFIED` до live provider/runtime evidence.
