# Миграция ADWF v1.5 → v1.6

Канонический скрипт: `.adwf/migrate_v1_5_to_v1_6.py`.

Он выполняет backup → `PREPARED` journal → config/state → Effective Policy → schema readback → `COMMITTED`. При fault после config/state/policy выполняется rollback. Миграция не меняет GitHub rulesets, repository visibility, LICENSE, secrets, releases или production deployment: после неё live Control Plane остаётся `NOT_VERIFIED`, пока v1.6 bootstrap/reconciliation не прочитает provider обратно.
