# Решение владельца о LICENSE

ADWF не выбирает юридическую лицензию автоматически. Это решение владельца, а не техническая оптимизация.

Пока файл `LICENSE` отсутствует:

- внутренний аудит, установка и сборка проверяемого ZIP разрешены;
- `release.py --external` и GitHub/GitLab external release блокируются;
- ИИ не заявляет, что проект является open source или разрешён к распространению.

Перед публичным release владелец выбирает лицензию с учётом желаемых прав, гарантий и используемых third-party компонентов; ИИ затем добавляет точный текст, проверяет notices и повторно собирает manifest/archive.
